# Task 8 – Simple Sales Dashboard

## Objective
Create a basic sales dashboard using Tableau to show sales by month, region, and category.

## Dataset
- File used: Sample - Superstore.csv
- Important columns: Order Date, Sales, Profit, Region, Category

## Tools Used
- Tableau Public

## Steps Done
1. Imported the CSV file into Tableau.
2. Changed Order Date to Month-Year format.
3. Made three charts:
   - Line chart for sales over months
   - Bar chart for sales by region
   - Donut chart for sales by category
4. Added a region filter to the dashboard.
5. Arranged everything neatly in a dashboard view.

## Insights
1. West region had the highest sales overall.
2. Technology category made the most sales.
3. December had the highest monthly sales.
